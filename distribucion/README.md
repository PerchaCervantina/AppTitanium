# Descarga directa de la app Titanium

Este `.apk` es la versión pública para instalar la app sin pasar por
Google Play (no tiene nada que ver con las cuentas de administrador ni
con Firebase App Distribution, que es solo para probar versiones con un
grupo cerrado).

Enlace de descarga directa para compartir (redes, web, cartel con QR...):

```
https://github.com/PerchaCervantina/AppTitanium/raw/feature/admin-accounts/distribucion/titanium.apk
```

Al tocar el enlace desde el móvil, se descarga el `.apk`. La primera vez,
el teléfono pedirá permiso para "instalar aplicaciones de orígenes
desconocidos" (para la app con la que se abra el enlace, normalmente el
navegador) — es normal al instalar fuera de Google Play, hay que
aceptarlo.

## Actualizar esta versión

Cada vez que haya una versión nueva que repartir al público, hay que
sustituir este fichero `titanium.apk` por el nuevo build y subirlo
(commit + push) a este mismo sitio — el enlace de arriba no cambia.
